# Event Management System

A web-based Event Management System for creating, managing, and registering events using Python, HTML, CSS, and MySQL.

## Features

- User Authentication
- Event Creation and Management
- Event Registration
- View Available Events
- Registration Management

## Technologies Used

- Python
- HTML
- CSS
- MySQL

## Project Description

This system helps users create, manage, and register for different types of events such as college cultural fests, technical symposiums, and wedding events.
